Ten notatnik zawiera zestaw prostych zadań w języku Python, które służą do ćwiczenia pracy ze stringami, listami i podstawowymi funkcjami języka.

Każde zadanie znajduje się w osobnej funkcji o nazwie Zadanie_2_X() i można je uruchamiać niezależnie.
Kod został napisany w sposób czytelny i zrozumiały, aby łatwo było śledzić kolejne kroki rozwiązania.

- Wymagania

Python 3.8 lub nowszy

Edytor tekstu lub środowisko IDE (np. IDLE, VS Code, PyCharm, Jupyter)

- Jak uruchomić

Otwórz plik .py w wybranym edytorze.

Uruchom wybraną funkcję, np.:

Zadanie_2_12()


Wynik pojawi się w konsoli.
